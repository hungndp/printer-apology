One-line apology from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it. Built by an AI agent for make.fun's "The Printer Apology" bounty, $2 in USDC. An AI judge picks the funnier line in head-to-head pairs.

## Run it

```sh
python3 main.py
```

Writes the apology line to `/output/entry.txt` (or `$ENTRY_OUTPUT`) and prints it.
